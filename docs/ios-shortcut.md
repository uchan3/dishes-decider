# iOS ショートカットからレシピを取り込む

共有シートからレシピを 1 タップで保存するための設定手順（Spec US-01 / architecture §3.2）。
App Store 配信をしない＝ Share Extension が使えないため、iOS の「ショートカット」アプリで代用する。

## 事前に用意するもの

1. PWA に**ログイン**する
2. 設定 →「取り込み（iOS ショートカット）」で **トークンを発行**する
   - 発行時に一度だけ表示される。閉じると二度と見られない（DB にはハッシュしか保存していない）
   - 端末ごとに分けて発行しておくと、失くした端末の分だけ失効できる
3. 同じ画面に出ている**送信先 URL**（`https://<project>.supabase.co/functions/v1/ingest`）を控える

## ショートカットの作り方

「ショートカット」アプリ →「+」→ 右上の詳細（ⓘ）で **「共有シートに表示」をオン**にし、
受け取る種類を **URL と Safari Web ページ** にする。次のアクションを上から並べる。

| # | アクション | 設定 |
|---|---|---|
| 1 | テキスト | `ショートカットの入力` を入れる（＝共有された URL） |
| 2 | URL の内容を取得 | URL: 上のテキスト。**方法: GET**。「内容を JavaScript で処理」は使わない |
| 3 | URL の内容を取得 | URL: 控えた送信先。**方法: POST**、本文: JSON |

3 番目のアクションのヘッダと本文:

**ヘッダ**

| キー | 値 |
|---|---|
| `x-ingest-token` | 発行したトークン |
| `Content-Type` | `application/json` |

**本文（JSON）**

| キー | 値 |
|---|---|
| `url` | 1 のテキスト（共有された URL） |
| `content` | 2 で取得した内容 |
| `contentKind` | `html` |

`content` を付けて送るのが要点で、**ページの取得を端末側で行う**ことで Bot 対策のあるサイトでも
本文が取れる（サーバーから取りに行くとデータセンター IP として弾かれる）。
`content` を省略すると Edge Function 側が自分で取得しにいく。

> YouTube は概要欄が `<script>` の中にあり、ショートカットの「Web ページ」変換で消えてしまう。
> Edge Function 側に `YOUTUBE_API_KEY` を設定しておくと Data API から概要欄を直接取得するので、
> YouTube の場合は `content` の有無にかかわらずそちらが優先される。

## 使い方

Safari / YouTube / Instagram の共有シート → 作ったショートカットを選ぶだけ。
Edge Function は即 202 を返すので、**ショートカットは数秒で完了する**（抽出は裏で 5〜15 秒かかる）。
取り込みが終わると PWA 側に Realtime で届き、レシピライブラリに増える。

## うまくいかないとき

PWA の 設定 →「取り込み（iOS ショートカット）」→ **取り込み状況** を見る。

| 表示 | 意味 | 対処 |
|---|---|---|
| 処理中 | 抽出中（通常 5〜15 秒） | 少し待って「更新」 |
| 完了 / 一部のみ | 保存済み（一部のみ＝材料か手順が欠けている） | ライブラリで確認・手で補う |
| 失敗 | 抽出でエラー | 表示されたエラー文を確認。ページ構造が特殊な場合は手動登録が早い |
| 停止 | 10 分以上応答なし | もう一度共有シートから送り直す |

**401 が返る場合**はトークンが違うか失効している。設定画面で発行し直す。
**429** はレート上限（1 時間 60 件）。
